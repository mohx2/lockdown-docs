\# Frequently Asked Questions



\### What is Lockdown?



Lockdown is a Windows application that helps you stay focused by restricting access to distracting applications and websites during focus sessions.



\### Is Lockdown free?



Yep! Lockdown is free right now. If you download it while it's free, you'll keep it free even if we introduce paid versions in the future.



\### Which operating system does Lockdown support?



Lockdown is currently designed for Windows.



\### How does website blocking work?



Website blocking is handled through the Lockdown Chrome extension, which works alongside the desktop application.



\### Do I need the Chrome extension?



You only need the extension if you want website blocking. Application blocking is handled by the Windows desktop application.



\### Can I choose which applications and websites are allowed?



Yes. Lockdown lets you configure an allowlist of applications and websites that you can access during your focus sessions.



\### Can I end a focus session early?



Lockdown includes an emergency exit mechanism for situations where you need to end a session before it finishes.



\### Does Lockdown collect my personal data?



Lockdown is designed to operate locally on your device without requiring an account. For more information, see our \[Privacy Policy](PRIVACY.md).



\### Something isn't working. What should I do?



Make sure Lockdown is running and, if you're using website blocking, that the Chrome extension is installed and enabled.



If you're still having trouble, visit the \[official website](https://lockdowned.pages.dev).
