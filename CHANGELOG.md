\# Changelog



All notable changes to Lockdown will be documented here.



\## \[1.0.0] — Initial Release



\- Application blocking for Windows

\- Website blocking through the Chrome extension

\- Custom application and website allowlists

\- Focus sessions

\- Emergency exit mechanism

\- Desktop application and browser extension integration

\## \[1.0.1] Block Scheduler update


\- You can now schedule focus sessions for any time and any duration you want using our app
