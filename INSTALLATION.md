\# Installation



Getting started with Lockdown is pretty straightforward.



\## 1. Download Lockdown



Head over to the \[official website](https://lockdowned.pages.dev) and download the latest version of Lockdown for Windows.



\## 2. Install the Application



Run the downloaded installer and follow the setup instructions.



Once installed, open Lockdown.



\## 3. Set Up Website Blocking



If you want to block websites as well, you'll need the Lockdown Chrome extension.



Install and set up the extension by following the instructions provided on the website.



\## 4. Configure Your Allowlist



Choose the applications and websites you want to have access to during your focus sessions.



Anything outside your allowlist will be restricted while your session is active.



\## 5. Start Focusing



Once everything is set up, start a focus session and get to work.



\---



If you run into any issues during installation, check the \[FAQ](FAQ.md) or visit the \[official website](https://lockdowned.pages.dev).
